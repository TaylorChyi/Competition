# Competition Bot · 直接上传最新包

在 [最新 Release](https://github.com/TaylorChyi/Competition/releases/latest) 的 Assets 中下载 **`CoreGeek.tar.gz`**，直接交给比赛平台，无需编译、安装依赖或重新打包。也可使用[最新包直达链接](https://github.com/TaylorChyi/Competition/releases/latest/download/CoreGeek.tar.gz)。只保留最新比赛包 Release，源码仓库不再存放压缩包。

## 平台解压与启动

压缩包采用官方 Demo 的单一顶层目录 `CoreGeek/`。解压到 `/home/docker` 后，启动入口应为：

```text
/home/docker/CoreGeek/main3.py
```

当平台已将文件放在该位置时，使用：

```bash
python3 /home/docker/CoreGeek/main3.py 6666
```

`6666` 来自本次正常运行日志，仍以平台指定端口为准。也支持 `bash /home/docker/CoreGeek/run.sh 6666`。程序监听 `0.0.0.0:<port>`，通过 HTTP 接收游戏状态并返回动作；保持前台运行。

如果仍报 `can't open file ... main3.py`，Python 尚未执行算法。若平台允许修改启动命令，请复制当前 Release 说明中的“预检启动命令”：它会打印 `/home/docker` 下的目录和 `main3.py` 候选位置，再启动与本次包清单匹配的唯一入口。这样也能处理平台额外套一层目录的情况。该命令无须下载文件或安装依赖。

若平台只接受固定启动路径，需要平台确保解压后实际存在 `/home/docker/CoreGeek/main3.py`；包内程序无法在自身文件尚未找到时修正该路径。具体日志含义见[平台启动排查](https://github.com/TaylorChyi/Competition/blob/main/docs/平台启动排查.md)。

接收者不需要搭建编译环境。程序使用比赛平台已有的 Python，最低要求为 3.11；包内不包含 Python 解释器，不需要第三方 Python 库、GPU、模型下载或 API Key。用户提供的正常日志显示解释器为 `/usr/local/bin/python3.11`；具体补丁版本未知。

## 可选：连通性检查

启动日志应先显示 `CoreGeek startup | package=... python=... entry=... runtime=...`，然后是 `listening on 0.0.0.0:6666`。`package` 指纹用于区分上传的新旧包。

服务启动后，在日志中 `runtime=` 指向的目录运行：

```bash
curl -sS -H 'Content-Type: application/json' \
  --data-binary @sample-request.json http://127.0.0.1:6666/
```

应返回包含 `roleCommandMap` 的动作 JSON。比赛平台负责连续提供状态和结算动作。

## 可选：范围攻击试验策略

默认是最近目标策略；试验范围策略需要显式启用：

```bash
COMPETITION_ROCKET_POLICY=selected-policy.json \
  python3 /home/docker/CoreGeek/main3.py 6666
```

试验策略在合成场景中清怪更多、基地损伤也更多，尚未替换默认策略。停止服务、取消该环境变量并使用普通命令即可恢复默认。

## 包内内容

`CoreGeek/main3.py`、`CoreGeek/src/agent/` 和 `CoreGeek/run.sh` 是运行入口与算法；所有文件均在同一个 `CoreGeek/` 目录内。`selected-policy.json` 是可选策略配置；`sample-request.json` 是请求样例；`MANIFEST.json` 记录运行目录各文件的 SHA-256。`pyproject.toml` 仅说明 Python 版本，直接启动不需要安装项目。

该版本包含基础采集建设、提前回防和按可开火状态分配炮手。每回合记录基地血量、金币、角色/炮台血量、机器人数量、动作及上回合失败反馈。新闻、宝藏、自进化任务解题尚未实现；正式比赛成绩尚未验证。
