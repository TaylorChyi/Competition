# Competition Bot · 接收方启动说明

本包是《未来战争》参赛程序的当前试跑版本。包含 HTTP 服务与策略代码，无第三方 Python 运行依赖。默认使用最近目标策略；范围选点实验策略可选启用。

## 1. 环境

- Bash。
- Python 3.11 或更高版本，命令名为 `python3`。
- 不需要安装 pip 依赖，不需要 GPU、模型下载或 API Key。
- 当前已在 macOS / Python 3.14.6 下验证解压启动与请求响应；正式 Linux 环境和比赛提交格式待主办方确认。

## 2. 启动

解压后进入 `run.sh` 所在目录：

```bash
bash run.sh 8080
```

`8080` 是示例端口，判题系统可替换为其指定端口。服务监听 `0.0.0.0:<port>`，保持前台运行；接收 HTTP POST JSON，返回包含 `roleCommandMap` 的 JSON。

如果 Python 的命令名称不同，可指定可执行文件：

```bash
PYTHON=/path/to/python3 bash run.sh 8080
```

## 3. 发一个样例请求

保持服务运行，在另一个终端进入相同目录，执行：

```bash
curl -sS -H 'Content-Type: application/json' \
  --data-binary @sample-request.json http://127.0.0.1:8080/
```

应返回形如 `{"roleCommandMap": {...}}` 的动作 JSON。终端会打印决策日志，不会出现网页界面。判题系统负责连续提供游戏状态和结算动作。

## 4. 可选：试验范围攻击策略

在 `run.sh` 所在目录执行以下命令，环境变量指定随包附带的策略文件：

```bash
COMPETITION_ROCKET_POLICY="$PWD/night-demo/selected-policy.json" bash run.sh 8080
```

试验策略在合成场景中平均击杀积分更高，但基地损伤也更多，因此没有设为默认。需要恢复最近目标时，停止服务后执行普通启动命令，并确保没有额外导出 `COMPETITION_ROCKET_POLICY` 环境变量。

## 5. 包内文件

- `run.sh`：启动入口，必须保留和 `bot/` 的相对位置。
- `bot/main3.py`、`bot/src/agent/*.py`：HTTP 服务与算法代码。
- `bot/pyproject.toml`：项目与 Python 版本信息；直接启动不需要先安装项目。
- `night-demo/selected-policy.json`：可选范围策略配置，不是神经网络权重。
- `sample-request.json`：上游公开请求样例，用于连通性检查。
- `MANIFEST.json`：各文件的 SHA-256，便于核对包内版本。

该包没有包含网页回放、模拟器、训练工具、Git 历史或本机运行记录。当前主要是基础采集建设和夜间防守；新闻、宝藏、自进化任务解题尚未实现。启动成功只证明可运行，不代表已通过正式比赛验收。
