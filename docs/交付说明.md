# Competition Bot · 接收方启动说明

本包是《未来战争》参赛程序的当前试跑版本，无第三方 Python 运行依赖。默认使用最近目标策略；范围选点实验策略可选启用。

## 1. 修复说明：main3.py 必须在程序根目录

旧版 `competition-bot-a3e382295cd5.zip` 将入口放在 `bot/main3.py`，仅验证了 `run.sh`，不兼容平台固定启动 `/home/docker/CoreGeek/main3.py` 的方式。新版已按原始 Demo 恢复 `main3.py + src/` 目录布局，算法不变。

新版提供两种包装，选一种使用：

- **`CoreGeek.tar.gz`（推荐）：**与上游 `Demo/CoreGeek.tar.gz` 一样，包含顶层 `CoreGeek/` 文件夹。解压目标是 `/home/docker`。
- **`CoreGeek-flat.zip`：**压缩包内直接是 `main3.py`、`src/` 等文件。仅用于平台已经将解压目录设为 `/home/docker/CoreGeek` 的情况。

无论用哪种包装，最终必须得到：

```text
/home/docker/CoreGeek/
├── main3.py
├── run.sh
├── pyproject.toml
├── src/agent/...
├── selected-policy.json
├── sample-request.json
├── README.md
└── MANIFEST.json
```

**不能多套一层 `CoreGeek/CoreGeek/`，也不能只上传 `main3.py` 而遗漏 `src/`。**

## 2. 环境与启动

Python 3.11 或更高版本；使用 `run.sh` 时还需 Bash。不需要安装 pip 依赖，不需要 GPU、模型下载或 API Key。

平台可直接使用其现有命令：

```bash
python3 /home/docker/CoreGeek/main3.py 8080
```

也支持进入 `CoreGeek` 目录后执行：

```bash
bash run.sh 8080
```

`8080` 替换为判题系统指定端口。两种启动方式均监听 `0.0.0.0:<port>`，保持前台运行；接收 HTTP POST JSON，返回包含 `roleCommandMap` 的 JSON。若 Python 的命令名称不同，可设置 `PYTHON=/path/to/python3 bash run.sh 8080`。

新版验证覆盖解压后的两种入口、默认和试验策略；本地验证环境是 macOS / Python 3.14.6，正式 Linux 环境尚待实际复测。

## 3. 发一个样例请求

保持服务运行，在另一个终端进入 `CoreGeek` 目录：

```bash
curl -sS -H 'Content-Type: application/json' \
  --data-binary @sample-request.json http://127.0.0.1:8080/
```

应返回形如 `{"roleCommandMap": {...}}` 的动作 JSON。终端会打印决策日志，不会出现网页界面。判题系统负责连续提供游戏状态和结算动作。

## 4. 可选：试验范围攻击策略

在 `CoreGeek` 目录执行：

```bash
COMPETITION_ROCKET_POLICY="$PWD/selected-policy.json" bash run.sh 8080
```

直接启动 Python 也可设置同一环境变量。策略配置路径应使用绝对路径。试验策略在合成场景中平均击杀积分更高，但基地损伤也更多，因此没有设为默认。恢复默认时，停止服务后执行普通启动命令，并确保没有额外导出 `COMPETITION_ROCKET_POLICY` 环境变量。

## 5. 包内文件与范围

- `main3.py`、`src/agent/*.py`：HTTP 服务与算法；必须保留相对位置。
- `run.sh`：同一程序的 Bash 入口。
- `pyproject.toml`：Python 版本信息；直接启动不需要安装项目。
- `selected-policy.json`：可选范围策略配置，不是神经网络权重。
- `sample-request.json`：上游公开请求样例，用于连通性检查。
- `MANIFEST.json`：各文件的 SHA-256，便于核对版本。

包内没有网页回放、模拟器、训练工具、Git 历史或本机记录。当前主要是基础采集建设和夜间防守；新闻、宝藏、自进化任务解题尚未实现。启动成功只证明可运行，不代表通过正式比赛验收。
