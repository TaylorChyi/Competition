# 三 Agent 锦标赛

用户于2026-09-18更新赛制后开始。Alpha、Beta、Gamma均使用GPT-6 Astra，固定复用同三位Agent；每轮先继承共同基线，独立优化并相互审查反例，冻结代码后由同一裁判比赛。

## 赛制

- 三方两两对战，每对先打10组，每组包含同种子换边的两半场。基础轮共30组、60半场，每位候选参加20组。
- 所有配对使用相同的10个场景：就近攻击4个、优先操作员3个、推进基地3个。每半场最多十晚，从75金币、零炮台开始；比赛期间源码变动即中止。
- 按配对胜局/配对总局数统计胜率，平局单列、不计为胜利。最高胜率并列时，仅并列者每对加赛5组新场景；加赛独立列出，再并列继续5组，不通过姓名、分数小数误差或随机抽签指定冠军。
- 每次决出唯一冠军，经过回归、打包、Linux真实HTTP及下载一致性验证后，发布新的最新Release，再删除旧比赛Release。两个败者以冠军源码为下一轮起点，继续优化和反制。
- 100%目标定义为某个基础轮对两个候选20/20组全胜。它是记录范围内的结果，不代表未知对手、以后版本或正式判题器必胜；十晚存活数另外报告。

规则：[rules.json](../lab/tournament/rules.json)。执行：`python3 tools/run_tournament.py --round 1`。已有完整结果时只读返回；中途停止可在源码一致时续跑。

## 模型限制

首两晚35/36机器人数量来自用户实战摘要。用户已确认机器人每回合只能移动或攻击，目标为最近或挡路单位。机器人种类比例、后续增长、出生位置、完整寻路、等距目标选择和角色移动时序仍是本地假设；旧三种目标优先级保留为历史，其中advance/operators不再作为当前官方机制。任务、新闻、宝藏及直接玩家攻击未完整模拟。

因此，冠军发布表示这轮候选中胜率最高且产物通过运行验证。仍需正式平台对局确认生存效果；本地冠军不能替代这项证据。

## 新的前置门槛：十晚生存

用户于2026-09-18将任务更新为：先达到明确验收集的十晚100%存活，再恢复三Agent胜率赛。第5轮已完成且未达到十晚要求，先保留其发布；此后暂停互赛。`lab/survival/`记录独立生存诊断，固定对面只作为共享战场背景，不计算或排名对抗胜率。已确认机器人每回合只能移动或攻击，不再询问这一项。后续选择以生存率、最早毁基地回合及残余防御能力为依据，不能用更多对抗胜局掩盖自己活不过十晚。

当前生存研究的机制确认、围墙结构对照与独立验收见[十晚生存门槛](十晚生存门槛.md)。未通过该门槛前不新增锦标赛轮次。
