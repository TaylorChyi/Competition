## 优先确认

- **具体例子：**机器人距基地 3 格，旁边有围墙；它会直接攻击基地，还是必须先打挡路的墙？攻击距离内但不挡路的炮手会被攻击吗？墙是否阻挡机器人攻击？
- 当前 Demo：向基地简单寻路，比较“射程内最近单位”和“基地在射程内则优先基地”两个假设；这两种都不是对“挡路”的完整实现。攻击不检查遮挡。
- 影响：判断墙能否诱导攻击、优先杀谁，以及基地掉血是否真实。

### 2. 移动发生碰撞后，下一回合如何处理？

- 同一格争夺时全部停下已有文字说明；下回合会重新寻路、换候选格，还是重试原来的格子？相同距离路径如何选择？
- **具体例子：**A→B 的旧位置、B→空格，是否允许一起前进？三单位首尾串行移动如何处理？机器人之间交换位置是否也取消？
- 当前 Demo：起始占用格全部阻挡，暂不支持跟随腾出的格子；同格争夺取消，下回合同距离候选格随种子和回合变化。早期固定选择造成长期堵塞，已经修正并废弃该批性能结论。
