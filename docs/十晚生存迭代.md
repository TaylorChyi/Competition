# 十晚生存迭代：经济、升级与持续防守

更新：2026-09-18。默认策略为三座电磁炮、四格前排墙、经济与升级、炮手避险。

**本地第二晚复核全部通过；十晚稳定生存仍取决于机器人行为假设。** 独立种子上的 18 场复核产生 24 个新版阵营结果，全部撑过第二晚，13 个撑过十晚。两个阵营同处一局，其结果有关联，不能当作 24 场相互独立的比赛，更不能当作官方胜率。

## 这次实际修复了什么

1. **从只建造、不开经济，改为采集→卖矿→采购→升级。** 根据请求中的实际售价和商品价格决策；工人分开采矿，保留正在采集的分工，避免追逐对手即将采空的矿。开拓者运送升级券；基地受损时优先升级回血。
2. **补上跨夜维护。** 一名工人维护四格前排围墙，随后参与采矿；开局石矿过远时先赚钱。严重受损且没有对应升级券的炮台，会付费重建为一级，不能把重建当作无成本保留等级的维修。
3. **修正炮位、炮手和火力。** 炮位朝向地图中心并保留操作空间，操作员受威胁时就近换位；只对指向我方的机器人计收益，直射计算沿线阻挡，跨炮台分配伤害，优先清掉能快速击杀的威胁。
4. **修复实际调试中发现的卡顿。** 开拓者不再被“预留墙位让路”逻辑推回基地；撞车后尝试另一条路；路线同长时优先向目标前进。矿点被同伴占用时，不把正在采矿的人赶走。
5. **补上日落采购。** 已筹好资金的紧急基地采购可以跨过日落完成；夜里能使用带回的基地券或身边武器的升级券，避免资金足够却因回防错过回血。采购、建造共用的钱包在同回合统一扣预算。

本版仍是标准库程序，没有神经网络、模型下载、GPU、API Key 或新增运行依赖。

## 模型依据与限制

- `heavy-nearest`：机器人进入射程后攻击最近的目标阵营单位，前排墙和炮台可以吸收攻击。
- `heavy-advance`：机器人忽略旁边可攻击单位而继续逼近基地，进入基地射程后可以隔墙攻击基地。这是额外的压力假设，尚无正式引擎证据。
- 两种假设都保留原来的前三晚强波次：每阵营小/中/大/BOSS 数依次为 14/6/1/0、20/10/2/0、24/14/3/1。后续递增，十晚为 52/28/5/2，延长规则在候选搜索之前固定，没有为了过关减少波次。
- 原模拟只有石矿、没有交易和升级；本轮加入样例中的六个矿点、商店与售价，以及正文明确的买卖、使用、升级回血、覆盖重建。所有金币都来自实际动作，保留建造成本、矿点容量和跨夜损伤，不赠送装备或免费回血。
- 同时修复了模拟器矿点刷新时使用移动前占用格的问题：新矿不会刷新到刚移动的角色脚下。新旧程序在同一修正版模拟器中比较。
- 同回合争夺矿点最后一份资源会导致一方采集失败；该失败仍计入 `invalidCommands`，并另记 `resourceConflicts`。本轮独立复核新版共 4 次这类冲突，其余非法动作 0 次，纯粹打向对方机器人的开火 0 次。
- 机器人优先级、出生数量和位置、弹道边界格、同回合争夺处理仍是本地假设。任务、新闻、宝藏、召唤和玩家直接攻击尚未模拟。没有把不存在的任务收入填入经济。
- 官方任务书明确整场上限 10 天 / 1300 回合；这里跑完整时长，但波次和官方地图并未得到验证。固定场景上的存活不是正式比赛胜率。
