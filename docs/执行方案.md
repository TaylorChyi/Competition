## 已确认的信息和疑点

### 已确认

- 当前上游仅 `main` 分支，没有 Release；树中只有四个文档/示例文件和一个 Demo 压缩包。
- Demo 的 `pyproject.toml` 要求 Python >=3.11，无第三方运行依赖。
- HTTP 响应时限为 5 秒；普通 LLM 次数是每游戏日 3 次；自进化任务期间不受该次数限制。LLM 和命令结果下一轮返回。
- 沙盒不能访问外部网络，`executeCmd` 仅能在任务期间使用，命令限时 15 秒。

### 资料中的具体问题

1. `docs/response.txt` 在 `summonTreasure` 的 `targetPos` 后缺逗号，直接 JSON 解析在第 66 行失败；还重复列举角色 ID。接口文档说明它是动作变体目录，不能直接作为真实响应模板。
2. 请求示例里的一级加特林射程为 4、电磁炮为 7、火箭为全图，和任务书一级射程 3/6/10 不同。目前沿用 Demo：优先读取实际输入 `attackRange`，缺省才查等级表；真实环境再核对。
3. 请求示例缺少接口文档中的部分字段，如任务 `timeoutRounds` 和机器人 `targetTeam`。样例不能当作完整接口契约。
4. 建造区域需要确认：目前沿用 Demo 按基地几何生成的位置，尚未证明在正式地图上全部合法。
5. 防守和任务的真实收益比例未知；样例积分、怪物分布不能当作完整比赛统计。宝藏奖励如何计入总分也需要实际回放确认。
