## 1. 这次具体试了什么

固定 3 座二级火箭炮、3 名炮手、3 段一级墙和一座 1500 HP 基地，抵御同一波 36 个合成机器人，持续 60 回合。比较的是火箭落点选择；没有计算购买和升级这些工事的白天成本。

两块地图是同一初始局面的独立模拟，彼此不交战。它们不是完整的双方比赛，也不构成自博弈训练。

| 策略 | 做法 |
| --- | --- |
| 最近目标 | 每轮把所有导弹打向最近机器人；升级后的弹数同样用足，避免不公平地少发弹 |
| 固定范围策略 | 按实际可造成的范围伤害挑落点，扣除其他导弹已计划的伤害 |
| 训练选定策略 | 从 8 组范围参数和最近目标共 9 组中选择；本次选中了范围策略加补刀奖励 15、威胁权重 0、开启伤害预留 |

选点允许打空格：一枚导弹落在几只机器人之间，可能比直接打单只更划算。伤害预留只影响规划，不会修改观测血量，也不会提前停止官方动作。

同一份选点代码被模拟器和真实 Bot 调用，因此可试用配置不是只有展示作用。默认保持最近目标；范围策略需显式启用。另修复升级火箭/加特林仍只提交一发目标的问题，当前基线也按等级提供弹数。

## 2. 实测结果：收益与代价同时存在

有效批次共 **72 场局部模拟**：36 场选参，36 场验证。每种验证策略 12 场配置，但只有 **3 个不同波次种子**，其余是左右镜像与两种机器人攻击目标假设，不能当作 12 个独立随机样本。

| 验证策略 | 存活场次 | 平均基地 HP / 1500 | 最低基地 HP | 平均击杀数量 | 平均击杀积分 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 最近目标 | 12 / 12 | 1488.3 | 1465 | 28.0 | 39.7 |
| 固定范围策略 | 12 / 12 | 1138.3 | 760 | 32.3 | 48.2 |
| 训练选定策略 | 12 / 12 | 1163.3 | 880 | 32.3 | 47.2 |

结论：

- 训练选定策略比最近目标平均多 **7.5 击杀积分，约 18.9%**，但平均少 **325 HP**。这只是本批合成场景的描述，不是可靠胜率提升。
- 自动选定策略并未全面超过固定范围策略：平均少 1.0 击杀积分、多 25 HP。还没有证据说明小规模自动选参优于简单手写范围策略。
- 所有策略都活过这一夜，不能宣称生存优势。血量没有直接折算成比赛积分；它在这里是后续夜晚的风险信号。
- 先保留默认最近目标，交付范围策略作为可试用方向。下一步先校准机器人攻击、移动和跨天血量，再决定如何处理清怪与保基地的取舍。

可能的解释是不同清怪顺序改变了机器人接近防线和基地的时机，但这仍是假设；不能只凭汇总数字认定原因。左右镜像的结果也可能不同：范围落点同分时使用坐标顺序破平局，当前没有保证策略完全镜像对称。

## 3. 怎么避免“自己模拟，自己宣布赢”

- 训练种子：`1101, 1202`；每个种子跑 2 种目标规则，共 4 个局面。按存活率、平均基地血量、击杀积分依次比较；并列保留较早候选。
- 训练集中最近目标平均 44.5 击杀分，选定策略为 50.0；两者基地均为 1500 HP。
- **参数先冻结，再运行验证**；验证种子 `1303, 1404, 1505` 没有参与本次选参。没有因为看到上述取舍而继续在验证集上调参数。
- 回放固定取验证集前两个局面，即种子 1303 的原侧与镜像、最近单位攻击规则；没有挑最好看的差距。
- 此前另跑了 72 场诊断批次。看回放发现机器人反复争同一格而长期堵塞，导致范围攻击收益被高估；修正等距离选路后，使用全新的训练与验证种子重跑。首批数字不用于最终性能结论。
- 初始诊断代码与结果保留在 Git 提交 `825c26a`，[诊断说明](../night-demo/initial-run-note.json)记录问题。累计实验场次为 144，另有小规模单元检查，不混入性能均值。

## 5. 如何运行与试用

直接打开下载后的 `night-demo/index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765/night-demo/index.html`。页面数据内嵌，不需要网络请求。

复现实验（会覆盖本地生成结果）：

```bash
python3 tools/run_night_demo.py
```

只用保存的数据重建页面，不再跑实验：

```bash
python3 tools/run_night_demo.py --render-only
```

启用实验火箭策略运行 HTTP Bot：

```bash
COMPETITION_ROCKET_POLICY="$PWD/night-demo/selected-policy.json" bash run.sh 8080
```

普通 `bash run.sh 8080` 保持最近目标。试验不改变正式环境的结算，最终行为仍由判题器决定。
